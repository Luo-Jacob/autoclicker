# AutoClicker

一个 Windows 上的**物理级**鼠标 / 键盘连点器。纯 Win32 `SendInput` 注入，多组绑定、独立全局热键、**一个热键同时驱动多种点击**、系统托盘常驻、无控制台窗口。

> 由 **Luo-Jacob** 制作 · 开源地址 <https://github.com/Luo-Jacob/autoclicker> · MIT License
>
> 使用 Python 3 + tkinter 编写，单文件源码，PyInstaller 打包为单个 exe。

## 功能

- **真实物理点击** —— 通过 `SendInput` 在当前光标位置按下并释放鼠标，不移动光标、不向窗口投递消息，与真人操作走同一条输入链路。
- **一个热键，多种点击同时进行** —— 一个绑定下可以挂任意多个动作，按下热键后这些动作**同时开始**、各自按自己的节奏独立重复。例如「左键每 60ms 点一次」+「F5 每 500ms 按一次」+「右键每 120ms 点一次」并行运行，互不干扰。
- **每个动作独立参数** —— 类型（左/中/右键、键盘按键或组合键）、间隔（毫秒）、随机波动（± 毫秒）、按下保持时长、重复次数（0 = 一直点到停止）。
- **四种动作** —— 鼠标左键 / 中键 / 右键，以及键盘按键（支持 Ctrl+A、Shift+F5 这类组合键）。
- **全局热键** —— 基于 `RegisterHotKey`，程序最小化到托盘、或在别的程序前台时同样响应。热键由用户自己录制，支持任意修饰键组合。
- **多组绑定** —— 每个绑定拥有独立的热键与独立的动作配置，互不干扰；支持新增、编辑、删除、单独启停。
- **设置项** —— 开机自动启动、关闭窗口行为（最小化到托盘 / 直接退出）、界面主题（亮 / 暗）、界面背景图、紧急停止热键。
- **配置持久化** —— 保存在程序同目录的 `AClib/config.json`；背景图片放在 `AClib/pictures/`。启动自动加载，修改后立即写盘（原子替换）。
- **三重紧急停止** —— 可配置的全局急停热键（默认 `Ctrl+Alt+K`）、常驻备用 `Ctrl+Alt+F12`、托盘菜单与界面上的红色急停按钮。

## 使用

1. 双击 `AutoClicker.exe` 启动（首次启动会在同目录生成 `AClib/config.json`）。
2. 点「＋ 新增」，在对话框里点「录制…」按下你要用的热键（例如 `Ctrl+Alt+X`）。
3. 在「点击动作」里点「＋ 添加」逐个加入动作，每个动作可设类型、间隔、波动、按下保持与重复次数。
4. 需要限制总量时填「总点击次数」（0 = 无限，一直运行到再按热键）。
5. 保存后把鼠标移到目标位置，按一下该热键开始；**再按一下即停止**。

### 多个动作是"同时"执行的

一个热键绑定三个动作：

| 动作 | 间隔 | 重复次数 |
| --- | --- | --- |
| 鼠标左键 | 60ms ±10 | 0（不限） |
| 键盘 F5 | 500ms | 0（不限） |
| 鼠标右键 | 120ms | 0（不限） |

按下热键后，三条点击流在**同一时刻**开始：左键约 16 次/秒、F5 每 0.5 秒一次、右键约 8 次/秒，同时进行到再按热键或触发急停为止。把某个动作的「重复次数」填成有限值（例如 3），它就点三下后自己停下，其它动作继续。

> 提示：鼠标三个键共用一个光标位置，多个鼠标动作同时运行时会交替落在同一个点上；常见用法是「鼠标 + 键盘」并行，或用不同间隔错开同一按键的节奏。

## 设置（「设置」窗口）

| 分组 | 选项 |
| --- | --- |
| 常规 | 紧急停止热键（可录制）、备用 `Ctrl+Alt+F12` 急停开关、关闭窗口时「最小化到托盘」或「直接退出程序」、开机自动启动（写 `HKCU\...\Run`）、开机启动后仅托盘、打开配置目录 |
| 外观 | 亮色 / 暗色主题（切换即时预览）、界面背景图（从 `AClib/pictures` 选择，选「浏览…」会自动把图片复制进该目录，可一键清除） |
| 关于 | 版本、作者、开源地址（可点击打开 / 复制）、许可协议 |

关闭主窗口的默认行为仍是收进系统托盘；改成「直接退出程序」后，点 × 就真正退出（热键也随之失效）。

## 默认热键

| 用途 | 默认热键 |
| --- | --- |
| 示例绑定的启停 | `Ctrl+Alt+X`（可在绑定里改成任意组合） |
| 紧急停止全部 | `Ctrl+Alt+K`（可在「设置」里改） |
| 备用紧急停止 | `Ctrl+Alt+F12`（常驻，可在设置里关闭） |

## 从源码运行 / 自行打包

需要 Python 3.9+（必须带 tkinter）。

```bash
pip install -r requirements.txt
python src/autoclicker.py           # 直接运行
```

打包成无控制台的单文件 exe：

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --noconsole --icon src/icon.ico --name AutoClicker \
  --hidden-import pynput.keyboard._win32 --hidden-import pynput.mouse._win32 \
  --hidden-import pystray._win32 src/autoclicker.py
```

产物在 `dist/AutoClicker.exe`。仓库里不提交 exe，请从 [Releases](../../releases) 下载。

## 实现说明

| 模块 | 做法 |
| --- | --- |
| 输入模拟 | `SendInput` + `MOUSEINPUT` / `KEYBDINPUT`，`wScan` 由 `MapVirtualKeyW` 取得，方向键等扩展键带 `KEYEVENTF_EXTENDEDKEY` |
| 全局热键 | `RegisterHotKey(hwnd=NULL)` 把消息投递到本线程队列，独立线程 `GetMessageW` 循环分发；注册/注销都通过 `PostThreadMessageW` 回到该线程执行 |
| 键位录制 | `pynput` 低层键盘钩子，仅在录制对话框打开期间存在，录制前会临时注销全部热键避免自触发 |
| 多动作并行 | 绑定存 `actions` 数组，每个动作一个独立线程（各自节奏、各自次数），按下热键同时启动；共享一个停止事件与总次数计数，达到上限或按热键时全部退出 |
| 线程模型 | 每个绑定一个管理线程 + 每个动作一个执行线程（`Event.wait` 做可中断的精确等待）；子线程从不触碰 tk 控件，界面更新统一投递到队列，由主线程 `after()` 轮询消费 |
| 主题 | 两套配色的字典，切换时重设 ttk 样式并更新已存在窗口的背景；列表标签色同步刷新 |
| 背景图 | Canvas 铺底，Pillow 按窗口比例 cover 缩放；内容面板取图片平均色与主题色混合（近似毛玻璃），窗口四周留 18px 露出原图 |
| 开机启动 | 写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，启动时与配置自愈同步 |
| 托盘 | `pystray` + Pillow 动态生成图标，运行中图标变绿 |
| 单实例 | 命名 Mutex，重复启动只提示不抢热键 |

## 已知限制

- 仅支持 Windows（依赖 `SendInput` / `RegisterHotKey` / 系统托盘）。
- 以管理员权限运行的游戏或全屏独占程序可能收不到注入输入，请让两者权限级别一致。
- 无修饰键的单键热键会全局独占该按键（例如把热键设成 `F8`，其它程序就收不到 `F8`），建议始终带一个修饰键。
- 热键可能被其它程序占用，此时界面上会提示注册失败。
- 背景图靠"面板取平均色"近似透明，不做逐像素半透明（tkinter 不支持控件级透明）。
