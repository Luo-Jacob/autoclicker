## Python GUI 版 v1.5.0

一个 Windows 上的**物理级**鼠标 / 键盘连点器。纯 Win32 `SendInput` 注入，
主界面分为「基础点击」与「节点循环」两个分区，另带**类 C 伪代码脚本**、多键组合热键、
定时启动、编号坐标库与方案预设、系统托盘、无控制台窗口。

> 使用 Python 3 + tkinter 编写，单文件源码，PyInstaller 打包为单个 exe。

### v1.5.0 界面美化

- **圆角卡片与排版** —— 圆角状态徽标、圆角胶囊分区标签、圆角表头与独立圆角行带；统一留白、字号层级与分组标题。
- **暗色主题细化** —— 重做深色中性底与分层卡片配色，输入框 / 下拉 / 滚动条 / 选中态统一细化，不再是亮色的简单反色。
- **表格视觉** —— 悬浮行高亮、斑马纹、运行状态色点、圆角选中行与 3px 强调条（自绘表格可深度定制）。
- **工具栏与徽标** —— 主次按钮分层（主操作蓝色、危险操作红色）、就绪 / 运行中 / 总点击改为彩色圆角徽标。
- **动态切换与个性化** —— 「设置 → 个性化」可选 5 套强调色、舒适 / 紧凑密度、圆角半径、切换动画与状态徽标开关，全部即时预览；主题切换做颜色插值过渡，分区指示条滑动。

## 功能

- **真实物理点击** —— `SendInput` 模拟按下 / 释放，不向窗口投递消息，与真人操作走同一条输入链路。
- **两个分区** —— 「基础点击」保留一个热键多动作**并行**执行；「节点循环」是 N 个节点**顺序循环**。
- **三种频率单位** —— `n±m ms/次`、`n±m 次/s`、以及「单位时间内随机 `n~m` 次」，每个动作独立设置。
- **坐标** —— 每个动作单选「跟随鼠标 / 固定坐标 / 编号坐标」，带鼠标坐标拾取器；固定坐标点击后可选恢复原光标。
- **结束条件** —— 时间（秒）、点击次数、或再按一次热键；任一动作先到条件，该组所有点击一起停。
- **最多 5 键组合热键** —— 除常规「修饰键 + 主键」外，可录制任意 5 个按键同时按下的组合。
- **定时启动** —— 倒计时 / 指定时刻 / 每日时刻，列表显示等待倒计时。
- **编号坐标库 + 方案预设** —— 坐标按编号引用，改一处全局生效；整套绑定 / 流程 / 坐标可另存为方案并一键切换。
- **高级脚本** —— 内置类 C 伪代码解释器，无头文件，用户自己写点击代码（默认关闭，需在设置里开启）。
- **三重急停** —— 可配置全局急停热键（默认 `Ctrl+Alt+K`）、常驻 `Ctrl+Alt+F12`、界面按钮 / 托盘菜单。
- **其它** —— 亮 / 暗主题（细化配色）、界面背景图（半透明面板 + 自绘表格完整透出）、个性化设置、开机启动、关闭窗口行为、配置原子写盘、单实例保护。

## 点击模式

> 下列各处的 `n`、`m`、`k` 都是**彼此独立**的参数，不共用变量。

### 分区① 基础点击

一个绑定 = 一个启动热键 + 一组**同时开始、各自独立计时**的动作。每个动作可设：

| 参数 | 取值 |
| --- | --- |
| 点击频率 | `n±m ms/次` 或 `n±m 次/s` 或「每 n ms 随机 m~m′ 次」（三种单位任选） |
| 热键绑定 | 组合键，或最多任意 5 个按键同时按下 |
| 点击坐标 | 跟随鼠标 / 自定义固定坐标 / 引用编号坐标 |
| 结束条件 | 时间 `n` 秒 / 点满 `n` 次 / 再按一次热键（急停） |
| 单点时长 | `n` ms（按下保持，可被急停打断） |
| 动作类型 | 鼠标左 / 中 / 右键、键盘按键（含组合键）、伪代码脚本 |

举例：左键 `100±20 ms/次`、F5 `2±0.5 次/s`、右键「每 1s 随机 3~8 次」三条流同刻开始，
节拍互不影响。任一动作点满或到时，整组一起停。

### 分区② 节点循环

一个流程 = 循环 `n` 轮 + 可选启动热键；每轮有 `k` 个动作节点，**按顺序**执行。每个节点可设：

| 参数 | 取值 |
| --- | --- |
| 点击次数 | `n` 次 |
| 点击坐标 | 跟随鼠标 / 自定义坐标 / 编号坐标（在「编辑动作」里设） |
| 点击频率 | `n±m ms/次`（次数 > 1 时生效） |
| 单机时长 | `n` ms（按下保持） |
| 单轮时长 | `n` ms（`0` = 不限；到时结束本节点进入下一节点） |
| 循环间隔 | `n` ms（本节点执行完后等待） |

流程级还可设：循环轮数（`0` = 无限）、全局循环间隔、总次数 / 总时长 / 手动结束、定时启动。

```
循环顺序：
  动作1 → 动作1的循环间隔 → 动作2 → 动作2的循环间隔 → … → 动作k → 动作k的循环间隔
  → 全局循环间隔 → 下一轮（共 n 轮）
```

### 高级：类 C 伪代码

在「设置 → 高级」启用后，可添加脚本动作，或从主界面点「脚本动作」直接新建一个脚本绑定。
**无头文件**，不需要 `#include`，直接写：

```c
hotkey("Ctrl+Alt+X");          // 首行声明该脚本的启动热键
int i;
for (i = 0; i < 10; i++) {
    left(mouse());             // 在当前鼠标位置左键点击
    pause(100);                // 间隔 100 ms
}
```

可用语法：`int`、`for`、`while`、`if else`、`break`、`continue`；
运算符 `+ - * / %  == != < <= > >=  && || !  ++ -- += -= *= /=`；
属性访问 `mouse().x` / `point(x, y).y`。

内置函数（`*` 为必填参数）：

| 函数 | 说明 |
| --- | --- |
| `rand(seed)` | 返回 10⁴~10⁵ 的随机数；`seed` 可选作随机种子；`rand(a,b)` 返回 a~b |
| `left(坐标)` / `right(坐标)` / `middle(坐标)` | 鼠标点击，坐标可省略（跟随鼠标） |
| `keyboard(*按键)` | 按下按键，如 `"A"` / `"Ctrl+Shift+F5"` / `"Enter"` |
| `pause(*ms)` | 等待 n ms，可被急停立即打断 |
| `hotkey(*按键)` | 模拟组合键；写在第一行时用于声明启动热键 |
| `mouse()` | 返回当前鼠标坐标，可用 `.x` / `.y` |
| `point(x, y)` | 构造坐标 |

坐标写法：`left()` / `left(mouse())` / `left(point(320, 240))` / `left(320, 240)`。

**安全**：解释器只能调用上表函数，没有文件、网络、模块导入、指针或任意函数定义能力；
有执行步数上限（默认 100 万步）与语法检查，运行随时可被热键 / 急停中断。

## 使用

1. 双击 `AutoClicker.exe`（首次启动在同目录生成 `AClib/config.json`）。
2. 在「基础点击」页点「＋ 新增」→「录制…」设启动热键 → 「＋ 添加」逐个配置动作。
3. 在「节点循环」页点「＋ 新增」建流程，逐个添加 / 编辑节点，设轮数与间隔。
4. 需要固定位置时，在动作里选「固定坐标」→「拾取…」，或先在「库」里存编号坐标再引用。
5. 按热键开始，**再按一次停止**；`Ctrl+Alt+K` 或界面红色按钮可急停全部。

顶部「当前方案」下拉可快速切换整套预设；「另存为…」把当前工作集存成新方案。

### 背景图与半透明面板

启用背景图后，**背景图会铺满整个窗口，包括表格在内的所有内容区都是半透明**，不再只露一圈边框：

- **面板容器**：每个容器内部铺一层底层 Canvas，按自身在窗口中的绝对位置用负坐标偏移绘制同一张
  「背景图 + 主题色」混成图，各区域拼接后与背景像素严丝合缝；标题、按钮、标签浮在图上。
- **主表格**：`ttk.Treeview` 的 field / heading 由 clam 引擎强制自绘不透明底色，样式、色键透明、
  `st.layout()` 都无法改变，因此 v1.4.6 起换成自写的 `GlassTable`（Canvas 自绘，保持 Treeview
  常用 API）。它从整窗磨砂图裁出表格对应的区域作底图，再用 RGBA 半透明叠加表头、交替行带、
  选中高亮与分隔线，文字用 `create_text` 浮在图上 —— **有数据的行也能看见背景图纹理**，
  同时文字保持清晰；支持选中、双击编辑、滚轮与滚动条、列宽自适应、亮暗主题。

窗口四周保留 18px 显示清晰原图。此实现不依赖色键或整窗透明，不会透出桌面或其他程序窗口。

在「设置 → 外观 → 面板不透明度」可拖动滑块调整（10% 最透 / 90% 最清晰，默认 45%），
拖动时即时预览，取消设置会还原。

主界面右下角「由 Luo-Jacob 制作」是**可点击链接**，点击打开项目
[最新版本页面](https://github.com/Luo-Jacob/autoclicker/releases/latest)（始终指向最新 Release，
不会因版本更新而失效）；关于窗口里另有「打开项目主页」与「最新版本」按钮。

## 从源码运行 / 自行打包

需要 Python 3.9+（必须带 tkinter）。

```bash
pip install -r requirements.txt
python src/autoclicker.py
python src/autoclicker.py --selftest     # 无界面自测, 结果写到 AClib/selftest.txt
```

打包成无控制台的单文件 exe：

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --noconsole --icon src/icon.ico --name AutoClicker \
  --hidden-import pynput.keyboard._win32 --hidden-import pynput.mouse._win32 \
  --hidden-import pystray._win32 src/autoclicker.py
```

Windows 下也可直接双击 `build.bat`。产物在 `dist/AutoClicker.exe`，仓库不提交 exe，请从 Releases 下载。

## 实现说明

| 模块 | 做法 |
| --- | --- |
| 输入模拟 | `SendInput` + `MOUSEINPUT` / `KEYBDINPUT`；`GetCursorPos` 拾取、`SetCursorPos` 固定坐标 |
| 全局热键 | `RegisterHotKey` 独立消息循环线程；多键组合用 pynput 低层钩子维护按下集合（边沿触发） |
| 基础点击 | 每动作一条线程，同刻启动，共享停止事件与计数；`Event.wait` 做可中断精确节拍 |
| 节点循环 | 单线程顺序状态机：节点 → 节点间隔 → 下一节点 → 全局间隔 → 下一轮 |
| 频率 | `ms` 用 `interval ± uniform(0,m)`；`cps` 采样 `n±m` 次/秒后取倒数；`window` 把随机次数散布到时间窗 |
| 脚本 | 自写 tokenizer + 递归下降 parser + 解释器，白名单内置函数，步数上限，可中断 |
| 定时启动 | 主线程 `after(500)` 检查；倒计时 / 指定时刻 / 每日时刻 |
| 线程模型 | 子线程绝不触碰 tk 控件，统一投递 `UI_QUEUE`，主线程 `after(250)` 轮询消费 |
| 配置 | `AClib/config.json`，schema v3；v2 配置自动迁移并生成 `#1 默认方案`；写盘用临时文件 + 原子替换 |
| 托盘 / 主题 / 背景 | `pystray` + Pillow 图标；两套 ttk 配色；Canvas cover 缩放；**面板容器用底层 Canvas + 负偏移绘制半透明磨砂图**（PIL `Image.blend`），不透明度可调 |
| 主表格 | `GlassTable`：Canvas 自绘 + PIL `alpha_composite` 半透明圆角行带 / hover / 状态色点，兼容 Treeview 常用 API；底图取磨砂图裁片，故表格行也透出背景 |
| 个性化 / 动态切换 | `settings` 存 accent / density / radius / animations / badges；`set_theme` 覆盖强调色并在暗色下提亮；主题切换做模块级颜色插值，分区指示条用 `after` 分帧滑动 |
| 开机启动 / 单实例 | `HKCU\...\Run`；命名 Mutex |

## C++ 独立产品线

v1.5 起 C++ 不再是「文档里的参考骨架」，而是**独立产品线**：见 [`cpp/README.md`](cpp/README.md)。
[`cpp/studio.cpp`](cpp/studio.cpp) 是单文件 Win32 代码工作台（代码编辑器 + 初始模板 + 编译日志 +
一键真编译），写的是**真 C++ 代码**（不是伪代码 / 不是自写 DSL 解释器），点「编译」会把内置运行时
与你的代码合并后调用本机 `g++` / `clang++` 真正编译。
[`docs/CPP_PATH.md`](docs/CPP_PATH.md) 记录编译命令、迁移说明与「数据包级点击」的规划（**仅规划，不实现**）。

| 产物 | 体积 | 控制台 | DLL 依赖 |
| --- | --- | --- | --- |
| `AutoClickerCPP.exe`（工作台） | 573 KB | 无 | 仅系统 DLL |
| `AutoClickerScript.exe`（用户脚本产物） | **42 KB** | 无 | KERNEL32 / USER32 / msvcrt |
| `AutoClicker.exe`（Python onefile） | 约 31 MB | 无 | 已打包 |

实测（本机 Dev-C++ 自带 MinGW64 `g++ 4.9.2`）：工作台与脚本产物均编译通过，
PE 子系统为 GUI（无控制台），导入表只有系统 DLL；`--once` 模式真实注入 5 次点击验证通过，
工作台 UI 的「编译」按钮、语法错误报错、完整源码导出均已实测。

> 手写稿的「≤5 MB」目标 C++ 线已达成；Python 线用体积换完整 GUI / 托盘 / 三套运行模式。
> 编译器只在**编译时需要**，产物拷到任意 Windows 直接运行，无需 MinGW / VC 运行库。

## 已知限制

- 仅支持 Windows（依赖 `SendInput` / `RegisterHotKey` / 系统托盘）。
- 以管理员权限运行的程序可能收不到普通权限进程的注入输入，请让两者权限级别一致。
- 固定坐标点击会短暂移动物理光标；并行动作各设不同坐标时会争用同一个系统光标。
- 无修饰键的单键热键会全局独占该按键，建议使用组合键。
- 主表格为自绘 `GlassTable`（非 `ttk.Treeview`）：不支持列宽拖拽、列排序与单元格编辑，选中 / 双击 / 滚轮滚动均可用；对话框内的列表仍是原生 Treeview。
- `ttk.Notebook` 与 `ttk.Treeview` 的自绘背景无法透明，这是主分区改自制标签、主表格改 Canvas 自绘的原因。
- 「数据包级点击」只在文档中规划，不提供代码 / 驱动 / 绕过机制。
- C++ 工作台需要本机已安装 `g++` / `clang++`（工作台不自带编译器，否则违背「单文件极小」目标）；
  编译产物本身零依赖。旧的 `docs/clicker.cpp` 参考骨架已被 `cpp/runtime_template.cpp` 取代并移除。
- Python 版主题切换动画是几帧颜色插值，不是 GPU 渐变；可在「设置 → 个性化」关闭。
